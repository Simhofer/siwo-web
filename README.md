# Siwo Web

Siwo Web saves websites as web apps. Each user of a site has separate storage.
The notarized macOS app is in [Releases](https://github.com/Simhofer/siwo-web/releases): `SiwoWeb-macOS.zip`.

Siwo Web speichert Websites als Web-Apps. Dieselbe Website kann mehrere Nutzer haben, jeder mit eigenem Speicher.

Der macOS-Download liegt unter [Releases](https://github.com/Simhofer/siwo-web/releases), Datei `SiwoWeb-macOS.zip`. Die App ist mit der Developer ID von Simhofer GmbH signiert und notarisiert.
